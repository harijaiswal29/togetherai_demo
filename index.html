01 · THE BIG IDEA

Buy a car, or book a ride?

Open-source models are free to download, but running a big one needs expensive GPU hardware. Together AI is like a ride-hailing app for AI models. You say where you want to go, and they handle the car, the fuel and the driver.

🚗 Run it yourself Buying a car

  • Full control, full responsibility
  • Makes sense at very large, steady scale

🚕 Together AI Booking a ride

  • Start in about 5 minutes. Pay cents per million words.
  • Try 10 different models in an afternoon
🍕
Real-world example: You want to compare pizza from 5 restaurants. You don't build 5 kitchens. You order from each and taste. Together AI is the delivery app, and the open-source models are the restaurants.

04 · YOUR FIRST CALL

The anatomy of a request

Here is python/01_first_chat.py, a travel helper. Each numbered part is explained on the right.

python/01_first_chat.py
from together import Together

client = Together()   # ① reads TOGETHER_API_KEY

response = client.chat.completions.create(
    model="meta-llama/Llama-3.3-70B-Instruct-Turbo",   # ②
    messages=[                                           # ③
        {"role": "system",
         "content": "You are a friendly travel assistant. Answer in 5 bullet points."},
        {"role": "user",
         "content": "I'm going to Goa in December for 4 days. What should I pack?"},
    ],
    temperature=0.7,    # ④ creativity dial
    max_tokens=300,     # ⑤ answer length cap
)

print(response.choices[0].message.content)   # ⑥
print(response.usage)                        # ⑦ tokens you pay for
1

Client. Your connection to Together. It finds your key automatically.

2

Model. Which open-source model answers. Swap the string to switch brains.

3

Messages. The conversation so far. system = the rules, user = the human.

4

Temperature. 0 = same answer every time; higher = more varied.

5

max_tokens. A ceiling on answer length (and cost).

6

The answer lives at choices[0].message.content.

7

Usage tells you exactly how many tokens went in and out.

Messages, visualised

The messages list is a script for a play. Each line says who is speaking.

USER · the humanI'm going to Goa in December for 4 days. What should I pack?
ASSISTANT · the model's reply• Light cotton clothes

05 · THE SETTINGS YOU'LL ACTUALLY USE

Temperature: the creativity dial

Drag the slider. These are illustrative answers to “Suggest a name for a chai café.”, showing how the style changes.

temperature = 0.7

🎯 temperature

Use 0–0.3 for facts, extraction and code. Use 0.7–1.0 for writing and brainstorming.

📏 max_tokens

A hard cap on answer length. If the reply cuts off mid-sentence, raise this.

🧾 response_format

{"type": "json_object"} makes the model return JSON your code can parse. See demo 06.

06 · TOKENS & COST

You pay per token, like an electricity meter

A token is a chunk of text, roughly ¾ of an English word. Prices are quoted per 1 million tokens, with separate rates for input (your prompt) and output (the answer).

Visual approximation only. Real tokenizers differ slightly per model.

07 · STREAMING

Show words as they're written

Without streaming, the user stares at a blank screen until the whole answer is ready. With streaming, words appear immediately, like the typing effect in ChatGPT. Total time is the same, but it feels much faster.

❌ stream=False: wait for all of it
Press “Run both”…
✅ stream=True: word by word
Press “Run both”…
python/02_streaming.py
stream = client.chat.completions.create(
    model="meta-llama/Llama-3.3-70B-Instruct-Turbo",
    messages=[{"role": "user", "content": "Write a 4-line poem about monsoon rain in Mumbai."}],
    stream=True,                      # ← the only change
)
for chunk in stream:                  # chunks arrive as they're generated
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
🏏
Real-world example: Live ball-by-ball cricket commentary (streaming) vs reading the full match report in tomorrow's newspaper (non-streaming).
08 · CONVERSATION MEMORY

Models don't remember. Your code does.

Every API call is independent. To have a conversation, you resend the whole history each time and append the new message to the end.

python/03_chatbot_memory.py (core loop)
history = [{"role": "system", "content": "You are a helpful cooking assistant."}]

while True:
    history.append({"role": "user", "content": input("You: ")})
    reply = client.chat.completions.create(model=MODEL, messages=history)
    answer = reply.choices[0].message.content
    history.append({"role": "assistant", "content": answer})   # ← this IS the memory
    print("Bot:", answer)
🍽️
Real-world example: A new waiter comes to your table every few minutes. To get the right dish, you hand each one the full list of what you've already ordered and said.

10 · BEYOND CHAT

Embeddings: search by meaning, not keywords

An embedding model turns text into a list of numbers, which you can think of as GPS coordinates on a "map of meaning". Sentences that mean similar things sit close together, even if they share no words.

python/07_embeddings_search.py
vectors = client.embeddings.create(
    model="BAAI/bge-base-en-v1.5",
    input=faqs + [question],
).data
# score each FAQ by closeness (cosine similarity)
# → "How do I reset my password?" wins
📚
Real-world example: A librarian who understands that “I forgot my login” is the same problem as “reset password”, even though the words differ. This is the foundation of RAG: you find the right documents first, then ask the chat model to answer using them.

12 · WHEN THINGS GO WRONG

Common errors & quick fixes

You seeWhat it meansFix
TOGETHER_API_KEY … missingThe key isn't in your environmentexport TOGETHER_API_KEY=… or create .env
401 UnauthorizedKey is wrong, expired or has a stray spaceCopy it again from Settings → API Keys
402 / insufficient creditsYour balance is emptyAdd credit under Billing
404 model not foundTypo in model ID, or the model was retiredRun 00_list_models.py and copy the exact ID
400 … requires a dedicated endpointThe model isn't served on demand (serverless)Pick a serverless model, or deploy a dedicated endpoint
429 Too Many RequestsYou hit the rate limitSlow down or retry. The SDK retries twice automatically (max_retries)
Answer cut off mid-sentencemax_tokens was reachedIncrease max_tokens
